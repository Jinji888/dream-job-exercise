## Overview
The project consisted of a basic static webpage titled **(My Dream Job)** where I experimented with foundational structural tags and basic styling.

### Topics I studied and applied:
*   **HTML5 Structure:** Use of headings, paragraphs, lists (`<ul>`, `<li>`), tables, division blocks (`<div>`), and text highlighting (`<span>`).
*   **Basic CSS Styling:** Implementation of layout and design properties such as `width`, `height`, `background`, `color`, `margin`, and `padding`.
*   **Selectors:** Practice using basic CSS ID and class selectors.
*   **Media:** Integration of local/remote images using the `<img>` tag.
