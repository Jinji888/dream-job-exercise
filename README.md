# My Dream Job (Basic HTML & CSS Project) 

This is an extremely simple web development project created as part of a university assignment for UVEG. The main purpose of this repository is to demonstrate active learning and track my progress as I learn the fundamentals of web development.

## Purpose:
> This repository serves purely as a learning milestone. It highlights my journey into coding using HTML and understanding CSS and its rules, it is also demonstration of repository management, and utilizing GitHub to document my journey : )

## Overview
The project consisted of a basic static webpage titled **(My Dream Job)** where I experiment with foundational structural tags and basic styling.

### Topics I studied and applied:
*   **HTML5 Structure:** Use of headings, paragraphs, lists (`<ul>`, `<li>`), tables, division blocks (`<div>`), and text highlighting (`<span>`).
*   **Basic CSS Styling:** Implementation of layout and design properties such as `width`, `height`, `background`, `color`, `margin`, and `padding`.
*   **Selectors:** Practice using basic CSS ID and class selectors.
*   **Media:** Integration of local/remote images using the `<img>` tag.
